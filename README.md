# Паспорт задачи — этап 1

Первый рабочий этап MVP для AI Sana: бизнес создаёт черновик, получает минимум три уточняющих вопроса, заполняет редактируемую карточку и вручную подтверждает публикацию. Данные хранятся в SQLite. Каталог, рейтинг, команды и отклики будут следующими этапами.

## Запуск

Нужны Node.js 20+ и Flutter 3.47+.

```powershell
cd server
npm install
Copy-Item .env.example .env
npm start
```

В другом терминале из корня репозитория:

```powershell
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:3000
```

Для Android URL API должен указывать на адрес компьютера в сети; эмулятор Android обычно использует `http://10.0.2.2:3000`. Web сборка: `flutter build web --dart-define=API_BASE_URL=http://localhost:3000`.

## Как устроено

- `lib/main.dart` — Flutter интерфейс с бизнес-профилями и первым сценарием.
- `server/index.js` — Express API и SQLite в `server/data/passport.sqlite`.
- `server/prompt.md` — контракт AI: вход, JSON-выход и запрет на выдуманные факты.
- `server/.env.example` — переменные окружения без секретов.

Ключ OpenAI хранится только на сервере в `OPENAI_API_KEY`. Без него сервер явно сообщает о шаблонных вопросах. AI не публикует задачу: `/api/tasks/:id/publish` требует профиль владельца и `confirm: true`.

## Проверка этапа

Создайте идею длиной от 10 символов. Ответьте на вопросы, заполните название и потребность, сохраните карточку. Нажмите «Опубликовать» и подтвердите действие. Карточка появится в «Мои задачи» со статусом «Опубликована».

Следующий этап: детерминированный рейтинг 0–100, подсказки и общий каталог с фильтрами. Затем — команды, отклики и ручной выбор нескольких победителей
