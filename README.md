# Паспорт задачи

Flutter Web MVP для AI Sana. Бизнес превращает короткую идею в карточку, видит готовность по шкале 0–100 и вручную публикует задачу. Команды находят её в каталоге и отправляют предложения. Бизнес вручную выбирает одну, несколько или ни одной команды. Android проект сохранён в той же Flutter кодовой базе, но текущий этап сосредоточен на вебе.

## Запуск

Требуются Node.js 20+ и Flutter 3.47+.

Терминал 1:

```powershell
cd server
npm install
Copy-Item .env.example .env
npm start
```

Терминал 2, из корня проекта:

```powershell
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:3000
```

Собрать статические файлы веб-приложения: `flutter build web --dart-define=API_BASE_URL=https://YOUR-API-ORIGIN`. Сервер и Flutter Web должны быть доступны браузеру по указанным адресам. Для локального запуска ключ OpenAI не требуется.

## Что есть в MVP

- Создание черновика из идеи, минимум три уточняющих вопроса, ответы в соответствующих полях и редактируемый паспорт задачи.
- Серверный AI с JSON-контрактом в [`server/prompt.md`](server/prompt.md). Ключ хранится только в `server/.env`. При недоступности AI интерфейс явно показывает шаблонные вопросы. Неизвестные факты AI оставляет пустыми.
- Рейтинг и советы по недостающим полям. Формула: контекст и потребность 20; данные 20; результат 15; измеримые критерии 15; ограничения 10; пользователи 10; контакт и формат 10. Пустые и бессодержательные заполнители не дают баллы.
- Уровни: 0–39 «Черновик», 40–69 «Рабочая», 70–89 «Готовая», 90–100 «Приоритетная».
- Общий каталог всех опубликованных задач, включая низкий рейтинг. Сортировка по баллу, фильтры по теме и уровню, поиск.
- Пять тестовых опубликованных карточек разной полноты, пять черновиков, пять команд и пять откликов. Демо-данные создаются один раз при первом запуске SQLite. Контакты вымышленные.
- Форма отклика команды с идеей, планом, сроком и необязательной ссылкой на прототип; список откликов для бизнеса; ручные решения «Выбрать» и «Отклонить». Можно выбрать несколько команд.
- Явное переключение роли и тестового профиля без регистрации.

## Архитектура и данные

`lib/` содержит Flutter интерфейс и клиент API. `server/index.js` — Express маршруты, AI вызов и SQLite. `server/rating.js` — детерминированный расчёт. База создаётся в `server/data/passport.sqlite` и игнорируется Git. Секреты хранятся только в локальном `server/.env`; пример без ключей — `server/.env.example`.

AI не считает рейтинг и не принимает решения о командах. Публикация требует явного `confirm: true` от профиля владельца. Изменение опубликованной карточки тоже требует подтверждения. Ответы и отклики сохраняются в общей базе.

## Проверки

```powershell
cd server
npm test
```

Из корня проекта: `flutter analyze` и `flutter build web`. API тест проходит черновик → вопросы → сохранение → публикацию, наличие низкорейтинговой задачи в каталоге и ручной выбор двух команд.

## Демо на 5 минут

1. Откройте каталог: покажите сортировку и задачу «Идея для экскурсионного сервиса» с уровнем «Черновик», которая остаётся видимой.
2. В роли бизнеса создайте идею, ответьте на вопросы, заполните карточку. Сохраните и покажите рейтинг с советами.
3. Подтвердите публикацию. Переключитесь на команду, откройте задачу и отправьте отклик.
4. Вернитесь в профиль владельца, откройте задачу и вручную выберите команду. Покажите, что можно выбрать ещё одну.

## Граница текущего этапа

Веб-интерфейс и API готовы для локального демо. Облачная публикация и Android сборка ещё не выполнялись. Авторизация, загрузка файлов и чат не входят в хакатонный MVP.
